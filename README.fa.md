# چت‌بات (Chat bot)

[English](README.md) | **فارسی**

یک محیط چت هوش مصنوعی دوزبانه (فارسی / انگلیسی) که با React، TypeScript، Vite و Tailwind CSS ساخته شده و با یک بک‌اند کوچک Node.js به مدل‌های Google Gemini یا Paasta وصل می‌شود.

## امکانات

- **مدیریت گفتگوها** — ساخت، تغییر نام، سنجاق، بایگانی و حذف گفتگو، با دسته‌بندی سنجاق‌شده / امروز / ۷ روز گذشته / بایگانی
- **جستجو** در تاریخچه‌ی گفتگوها
- **پیوست تصویر و PDF** (کشیدن و رها کردن، حداکثر ۵ فایل، هرکدام تا ۱۰ مگابایت)
- **ورودی صوتی** با Speech Recognition API مرورگر
- **ویرایش پیام و تولید دوباره‌ی پاسخ**
- رابط **فارسی و انگلیسی** با پشتیبانی کامل از راست‌به‌چپ
- **شخصی‌سازی** — انتخاب تصویر پس‌زمینه (رنگ‌های آن روی رابط اعمال می‌شود) و تنظیم میزان محوشدگی
- **تنظیمات** — حساب و عکس پروفایل، مدل هوش مصنوعی و دستورالعمل‌های سفارشی، خروجی گرفتن از داده و پاک کردن تاریخچه، اعلان‌ها، امنیت و راهنما
- **پاسخ واقعی هوش مصنوعی** از طریق بک‌اند پوشه‌ی [`backend/`](backend/README.md) (Gemini یا Paasta)
- ذخیره‌ی گفتگوها و تنظیمات در خود مرورگر (`localStorage`)
- انیمیشن‌های نرم با Framer Motion و طراحی واکنش‌گرا برای موبایل و دسکتاپ

## فناوری‌ها

- [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vite.dev)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Framer Motion](https://motion.dev)
- آیکون‌های [Lucide](https://lucide.dev)
- بک‌اند Node.js (بدون وابستگی) در `backend/server/`

## شروع به کار

نیازمند [Node.js](https://nodejs.org) نسخه‌ی ۲۰.۱۲ یا بالاتر.

```bash
git clone https://github.com/matinzeinali/chatbot.git
cd chatbot
npm install
npm run dev
```

سپس آدرسی را که Vite نشان می‌دهد (معمولاً http://localhost:5173) باز کنید.

در ویندوز می‌توانید روی `run.bat` دوبار کلیک کنید. این فایل نسخه‌ی Node.js (۲۰.۱۲ یا بالاتر) را بررسی می‌کند، در صورت نیاز وابستگی‌ها را نصب می‌کند، اگر کلید API تنظیم شده باشد و بک‌اند از قبل در حال اجرا نباشد آن را در پنجره‌ی جداگانه اجرا می‌کند، سپس سرور توسعه را بالا می‌آورد و مرورگر را روی همان پورتی که Vite گرفته باز می‌کند.

### دستورها

| دستور             | کار                                           |
| ----------------- | --------------------------------------------- |
| `npm run dev`     | اجرای سرور توسعه                              |
| `npm run server`  | اجرای بک‌اند هوش مصنوعی روی پورت 8787         |
| `npm run build`   | بررسی تایپ‌ها و ساخت نسخه‌ی نهایی             |
| `npm run preview` | پیش‌نمایش نسخه‌ی نهایی به‌صورت محلی           |

## اتصال به مدل هوش مصنوعی

1. فایل `backend/server/.env.example` را با نام `backend/server/.env` کپی کنید.
2. مقدار `GEMINI_API_KEY` (برای Google Gemini) یا `PAASTA_AI_KEY` (برای Paasta) را تنظیم کنید. اگر هر دو تنظیم شوند، Gemini استفاده می‌شود.
3. دستور `npm run server` را کنار `npm run dev` اجرا کنید. Vite درخواست‌های `/api` را به بک‌اند می‌فرستد.
4. از **تنظیمات ← هوش مصنوعی** مدل را انتخاب کنید.

ارسال پیام، تولید دوباره و ویرایش، کل تاریخچه‌ی گفتگو را به بک‌اند می‌فرستند. دستورالعمل‌های سفارشی **تنظیمات ← هوش مصنوعی** به‌عنوان پیام سیستمی ارسال می‌شوند و خطاها به‌صورت اعلان (toast) نمایش داده می‌شوند. اگر شناسه‌ی مدل ذخیره‌شده وجود نداشته باشد یا دیگر معتبر نباشد، سرور از مدل پیش‌فرض خودش (Gemini 3.6 Flash) استفاده می‌کند.

مسیرهای بک‌اند: `GET /api/health`، `GET /api/models` و `POST /api/chat`. محدودیت‌ها: پاسخ‌ها فقط متنی هستند (از پیوست‌ها فقط نام فایل به مدل فرستاده می‌شود، نه محتوای آن)، استریم پاسخ و ذخیره‌ی گفتگو روی سرور پیاده نشده و فهرست مدل‌های Gemini یک فهرست ثابت در `backend/server/models.mjs` است. مدل‌های Pro روی کلید فعلی به فعال بودن پرداخت (billing) نیاز دارند. کلید API را فقط در `.env` نگه دارید و هرگز در متغیرهای `VITE_` یا گیت قرار ندهید. جزئیات بیشتر در [`backend/README.md`](backend/README.md).

## ساختار پروژه

```
backend/
└── server/          # پراکسی API برای Gemini / Paasta (پورت 8787)
src/
├── components/
│   ├── chat/        # پنل چت، حباب پیام‌ها، کادر نوشتن، پیوست‌ها
│   ├── settings/    # پنل و بخش‌های تنظیمات
│   ├── sidebar/     # فهرست گفتگوها، برند، منوی حساب
│   ├── icons/       # آیکون‌های SVG سفارشی
│   └── ui/          # اجزای مشترک (دیالوگ‌ها)
├── context/         # زبان (فارسی/انگلیسی) و پس‌زمینه
├── data/            # گفتگوها، پیام‌ها و پس‌زمینه‌های نمونه
├── hooks/           # useSpeechInput، useDismiss
├── lib/             # کلاینت API و استخراج پالت رنگ
└── assets/          # تصاویر و فونت‌ها
```
